- **Spherical geometry** for cell cycle / periodic states

- **Multi-scale temporal dynamics** - fast/slow processes

## Data Extensions

- **Temporal data integration** - if longitudinal data becomes available

## Infrastructure Extensions

- **Real-time inference API** - serve model predictions
- **Interactive visualization** - explore embeddings dynamically
- **Uncertainty quantification** - Bayesian extensions
