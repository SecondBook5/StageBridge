## Key Principles

1. **Cells are the scientific unit** - Bags/lesions are containers, not science
2. **Receiver-centered architecture** - Information flows TO the receiver
3. **Dual-reference geometry** - HLCA (healthy) + LuCA (cancer) anchors
4. **Progression as objective** - Stage transitions, not just classification
